# Stock Picker

A Java program that loads historical stock data and lets  investors
filter and compare stocks based on their goal: short term or long term.

## The Problem

People want to get into investing to make some passive income, however they don't know the first thing how to correctly invest to maximize their profit

## How It Works

The program reads historical stock prices from a CSV file and calculates key metrics for each stock: total return, average annual return, and volatility. The user picks a goal (short term or long term),
and the program filters the stocks that fit that goal, compares them side by side in a console table, and ranks them with a plain-English explanation of why each one fits.

![System diagram](docs/diagram.png)

## Tech Stack

- **Language:** Java
- **Libraries:** OpenCSV, JUnit
- **External tools:** Historical stock prices in CSV format(Kaggle/Yahoo)
